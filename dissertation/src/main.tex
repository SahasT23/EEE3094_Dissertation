\begin{abstract}
Time series preprocessing methods typically discard the structural link between extracted features and specific events in the input signal. This report presents the Magnitude-Ordered Visibility Graph (MOVG), a framework that converts a time series into a directed acyclic hierarchy by combining geometric visibility checks with magnitude-based ordering. The hierarchy is decomposed into monotone chains, from which path-signature projections and structural descriptors produce a fixed-length feature vector. Every feature is traceable through a specific chain and set of graph nodes back to identifiable timestamps in the raw signal. When combined with SHAP attribution, this provenance enables a complete backtrace from model prediction to raw data.

The framework was formally specified, implemented as a Python package with 13 modules and 45 unit tests, and evaluated against FFT and wavelet preprocessing across seven datasets and six regression models. MOVG recorded the lowest mean RMSE on every dataset, with an average improvement of 15.1\% over the best non-MOVG baseline. A 32-feature reduced representation retained this performance advantage while supporting deterministic post-inference backtracing.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Accurate time series forecasting underpins decision-making across engineering, finance, and environmental monitoring. Current preprocessing methods, including spectral transforms and statistical feature toolkits, can achieve strong predictive performance but typically produce features that cannot be linked back to specific events in the input signal. When a model makes a prediction, the practitioner can identify which features mattered but not which part of the raw data produced those features. This opacity limits trust and actionability in safety-critical and high-stakes applications.

This project addresses the interpretability gap by developing a novel feature extraction framework called the Magnitude-Ordered Visibility Graph (MOVG). MOVG constructs a directed acyclic graph from a time series by combining pairwise visibility checks with a magnitude-based hierarchy. The graph is decomposed into monotone chains, and path signatures computed over these chains produce fixed-dimensional descriptors. Each descriptor is traceable through a specific chain, through specific graph nodes, to specific timestamps and amplitudes in the original signal.

The project produced three deliverables:

\begin{enumerate}[leftmargin=2em, itemsep=0.3em]
    \item A formal algorithmic specification of the MOVG framework, including definitions, proofs of acyclicity, pseudocode, and an installable Python package (13 modules, \texttt{pyproject.toml}, 45 unit tests).
    \item API documentation for the package in RESTful style, enabling future researchers to reproduce and extend the work.
    \item A preprocessing benchmark comparing MOVG features against FFT and wavelet baselines across seven datasets and six regression models, together with a post-inference backtracing tool that maps predictions to raw signal events.
\end{enumerate}

\section{Literature Review and Motivation}
\label{sec:lit-review}

\subsection{Time Series Feature Extraction}
\label{sec:lit-feature-extraction}

Raw time series are high-dimensional, temporally correlated, and often noisy. Although models can ingest sequences directly, feature preprocessing usually improves accuracy and efficiency. The preprocessing choice determines which information is preserved.

Spectral methods project signals into the frequency domain. The fast Fourier transform decomposes signals into sinusoidal components and reveals dominant periodicities [9, 12]. Recent work combines FFT amplitude and phase features with LSTMs to leverage time- and frequency-domain information [10]. Transformer variants using FFT-based preprocessing improve forecasting across sensor datasets by enriching representations with spectral structure [11].

Wavelet and modal methods provide joint time-frequency localisation [8]. MDCNet uses variational mode decomposition to separate trend and modal components and achieves strong long-horizon performance [23]. These approaches characterise frequency content or scale-specific energy but do not encode structural relationships between temporal events.

Statistical feature extraction remains in the time domain. Toolkits such as \textit{hctsa} compute large collections of scalar summaries including distributional statistics, autocorrelation measures, and entropy estimates. Deep learning models instead learn representations end-to-end from raw sequences. THATSN builds a temporal hierarchical tree from multi-cyclic decompositions and aggregates features using a gated LSTM to capture inter-cycle relationships [24]. Despite strong predictive performance, these learned representations are typically opaque.

Across both paradigms, the mapping from raw signal to feature is rarely transparent. Spectral coefficients, statistical summaries, and learned embeddings may support accurate predictions, but they do not provide a clear link between predictions and specific events in the input signal.

\subsection{Visibility Graphs for Time Series}
\label{sec:lit-visibility-graphs}

Visibility graphs map geometric relationships in time series to graphs: two points connect if no intermediate point blocks their line of sight [1]. This preserves temporal ordering and reflects underlying dynamics, since degree distributions distinguish periodic, random, and fractal processes [1]. Extensions include multiplex visibility graphs, where each channel forms a layer and inter-layer edges capture cross-variable dependencies [3, 4]. Broader overviews cover classification, clustering, and motif discovery [5], while applications to financial and synthetic data demonstrate extraction of short- and long-term structure [7].

Standard visibility graphs still have structural limitations. They are undirected, contain cycles, and lack a canonical traversal order. Systematic decomposition into interpretable substructures becomes computationally difficult. As a result, they are limited as preprocessing for machine learning. Graph-level statistics such as degree distribution or clustering coefficient can be used as features, but they cannot be linked to specific events in the original signal.

Figure \ref{fig:StandardVisibilityGraph} shows an example of a standard visibility graph constructed from a time series. The undirected edges reflect mutual visibility, but the presence of cycles and lack of hierarchy means that there is no straightforward way to decompose the graph into meaningful substructures for feature extraction. This motivates the need for a new approach that combines visibility with a magnitude-based hierarchy to produce a directed acyclic structure amenable to systematic decomposition and traceable feature extraction.

\subsection{Path Signatures in Machine Learning}
\label{sec:lit-signatures}

The signature transform, rooted in rough path theory, maps a sequential path to a graded sequence of iterated integrals that uniquely characterises it up to reparametrisation [2]. Linear functionals on signature terms are dense in the space of continuous functions on paths, providing a universal nonlinear feature map. The output dimensionality depends only on the embedding dimension and truncation depth, not solely on input length, a property well-suited to variable-length sequences.

A generalised signature framework has been developed and benchmarked across 26 multivariate classification tasks, achieving performance comparable to deep recurrent and convolutional architectures [2]. Applications span handwriting recognition, medical time series, and financial modelling. However, existing work applies signatures to raw or augmented time series. No prior method computes signatures over structurally decomposed paths derived from a graph-based representation of the signal.

\subsection{The Interpretability Gap}
\label{sec:lit-gap}

The methods surveyed above share a common structural deficiency: the chain of reasoning from raw signal to extracted feature to model prediction is opaque. FFT projects into the frequency domain, discarding temporal locality. Wavelet decomposition retains time-frequency resolution but commits to a fixed basis, and individual coefficients do not correspond to identifiable signal events. Standard visibility graphs encode pairwise geometric relationships but lack the directed, acyclic structure required for systematic decomposition. Deep learning methods learn representations end-to-end with no human-readable intermediate stage.

Post-hoc explainability tools such as SHAP can identify \emph{which} features drive a prediction. However, the explanatory value of a SHAP attribution depends entirely on the semantic content of the underlying feature. An attribution to a spectral coefficient or an autocorrelation statistic tells the practitioner that a particular frequency or correlation property mattered. It does not reveal which events in the raw signal produced that property.

This work addresses the gap by proposing a preprocessing method in which every extracted feature possesses full structural provenance. The Magnitude-Ordered Visibility Graph transforms a time series into an acyclic hierarchy admitting polynomial-time decomposition into monotone chains. Path signatures computed over these chains yield fixed-dimensional descriptors, each traceable through a specific chain, through specific graph nodes, to specific timestamps and amplitudes in the original signal. When combined with post-hoc attribution, this provenance enables a complete backtrace: from model prediction, through feature importance, through graph structure, to the raw data.

\section{Theoretical Background}
\label{sec:theory}

Two existing approaches motivate the design of MOVG. Standard visibility graphs, introduced by Lacasa et al.\ [1], convert a time series into an undirected graph by connecting any two points that have unobstructed line-of-sight. Because visibility is symmetric, cycles arise immediately: any three mutually visible points form a triangle. Consequently, no canonical traversal order exists, path enumeration grows exponentially, and the resulting graph cannot be systematically decomposed for feature extraction.

Min-max trees offer an alternative hierarchical view [17, 18]. A min-max tree recursively splits a time series at its global extremum, forming left and right subtrees. This produces a binary hierarchy that encodes dominant peaks at shallow levels and minor fluctuations at depth. However, the recursive bisection is entirely determined by index ranges and ignores the geometric relationships between points. Two points may be placed in the same subtree despite having no line-of-sight connection, or separated into different subtrees despite being geometrically adjacent. The structure therefore does not reflect the actual shape of the signal.


MOVG combines the geometric grounding of visibility graphs with the hierarchical organisation of min-max trees, while avoiding the limitations of both. It does so through two conditions applied simultaneously during an incremental construction: a \emph{visibility condition} that determines which connections are geometrically valid, and a \emph{magnitude ordering} that determines the parent-child hierarchy. The result is a directed acyclic forest in which every edge reflects both a real geometric relationship in the signal and a dominance ranking by amplitude. Cycles are impossible because each parent-child step moves to strictly smaller amplitude.

\subsection{MOVG Construction}
\label{sec:movg-construction}

MOVG is built incrementally. Each time series point is inserted in chronological order, and at each step the algorithm checks two conditions: whether the new point is visible to existing points, and which visible predecessor with larger amplitude should become its parent. The tree grows one node at a time, with the structure fully determined after the final insertion.

\subsubsection{Visibility Condition}

Two points $i$ and $j$ ($i < j$) in a time series $Y = \{y_0, y_1, \ldots, y_{n-1}\}$ are mutually visible if and only if no intermediate point breaks the line of sight between them:

\begin{equation}
y_k \leq y_i + (y_j - y_i) \cdot \frac{k - i}{j - i} \quad \forall\; i < k < j
\label{eq:visibility}
\end{equation}

In plain terms: draw a straight line from $(i, y_i)$ to $(j, y_j)$. If every point between them lies on or below that line, the two points can ``see'' each other. Adjacent points ($j = i+1$) are always visible because no intermediate point exists to block the view.

\subsubsection{Magnitude Hierarchy and Incremental Insertion}

The tree is constructed by processing points one at a time in chronological order. When a new point $n_i$ is inserted, the algorithm looks backward to all previously inserted points that are both \emph{visible} to $n_i$ and have \emph{strictly larger amplitude}. Among these candidates, it selects the one with the \textbf{smallest} amplitude as parent:

\begin{equation}
\text{parent}(i) = \arg\min_{c \in C_i} Y[c], \quad C_i = \{j : j < i,\; \text{visible}(j, i),\; Y[j] > Y[i]\}
\label{eq:parent-assignment}
\end{equation}

If a newly inserted point has larger amplitude than every previously inserted point, it becomes the new root and the former root becomes its child. If the candidate set $C_i$ is empty (no earlier visible point has larger amplitude), the node becomes a secondary root of a separate tree.

Selecting the \emph{smallest} larger visible predecessor (rather than the largest) produces a tight hierarchy. This means each node attaches to the ``closest ceiling'' above it rather than jumping directly to the global maximum. The result is that root-level nodes represent dominant peaks, leaf nodes represent minor fluctuations, and depth directly encodes amplitude significance.

The resulting structure is a \textbf{forest}: a collection of one or more trees. Secondary roots arise when a point appears in the time series before any point with larger amplitude. These early-arriving peaks have no valid parent candidate and form the roots of their own subtrees. The forest is provably acyclic because every parent-child edge connects a node to a strictly smaller-amplitude child. Any hypothetical cycle would require returning to a node with larger amplitude than its parent, contradicting the construction rule.

\begin{algorithm}[H]
\caption{Incremental MOVG Construction}
\label{alg:build-movg}
\begin{algorithmic}[1]
\Require Time series $Y$ of length $n$
\Ensure Forest $\mathcal{F}$ (parent map, level map, root set)
\Function{BuildMOVG}{$Y$}
    \State $\text{parent}[\cdot] \gets \text{nil}$;\quad $\text{level}[\cdot] \gets 0$;\quad $\text{root} \gets 0$
    \For{$i \gets 0$ \textbf{to} $n - 1$} \Comment{Insert nodes chronologically}
        \State $C \gets \emptyset$
        \For{$j \gets 0$ \textbf{to} $i - 1$} \Comment{Check all predecessors}
            \If{$\Call{IsVisible}{Y, j, i}$ \textbf{and} $Y[j] > Y[i]$}
                \State $C \gets C \cup \{j\}$
            \EndIf
        \EndFor
        \If{$C \neq \emptyset$}
            \State $\text{parent}[i] \gets \arg\min_{c \in C} Y[c]$ \Comment{Tightest ceiling}
            \State $\text{level}[i] \gets \text{level}[\text{parent}[i]] + 1$
        \ElsIf{$Y[i] > Y[\text{root}]$}
            \State Reparent former root under $i$;\quad $\text{root} \gets i$ \Comment{New global max}
        \Else
            \State Mark $i$ as secondary root;\quad $\text{level}[i] \gets 0$
        \EndIf
    \EndFor
    \State \Return $(\text{root}, \text{parent}, \text{level})$
\EndFunction
\end{algorithmic}
\end{algorithm}

The visibility check for each pair requires examining up to $O(n)$ intermediate points. Over $n$ insertions, each checking up to $n$ predecessors, the worst-case complexity is $O(n^3)$. In practice, visibility checks terminate early when an obstruction is found, and typical performance is closer to $O(n^2)$ for signals with moderate local structure.

    \item \textbf{Insert $n_0$ ($y{=}3$).} First node. No predecessors exist. $n_0$ becomes the root.

    \item \textbf{Insert $n_1$ ($y{=}1$).} The only predecessor is $n_0$ ($y{=}3$), which is visible (adjacent) and has larger amplitude. $n_1$ attaches to $n_0$ as a child at depth~1.

    \item \textbf{Insert $n_2$ ($y{=}4$).} Predecessors are $n_0$ ($y{=}3$) and $n_1$ ($y{=}1$). Neither has amplitude greater than~4, so no valid parent exists. The only valid candidate is $n_2$. $n_3$ attaches to $n_2$ at depth~1.

    \item \textbf{Insert $n_4$ ($y{=}5$).} No predecessor has amplitude greater than~5. $n_4$ becomes the new root. The previous root $n_2$ is reparented under $n_4$ (they are visible via the edge set).

    \item \textbf{Insert $n_5$ ($y{=}1$).} The only visible predecessor with larger amplitude is $n_4$ ($y{=}5$), which is adjacent. $n_5$ attaches to $n_4$ at depth~1.

    \item \textbf{Insert $n_6$ ($y{=}3$).} The visible predecessor with larger amplitude is $n_4$ ($y{=}5$). $n_6$ attaches to $n_4$ at depth~1.

    \item \textbf{Insert $n_7$ ($y{=}2$).} Visible predecessors with larger amplitude include $n_4$ ($y{=}5$) and $n_6$ ($y{=}3$). The smallest is $n_6$ ($y{=}3$), the tightest ceiling. $n_7$ attaches to $n_6$ at depth~2.
\end{enumerate}

The completed hierarchy is a forest with three trees. The primary tree is rooted at $n_4$ ($y{=}5$) with subtree $n_2$ ($y{=}4$) containing children $n_0$ and $n_3$, and direct children $n_5$ and $n_6$ with grandchild $n_7$. The forest mirrors the dominance structure of the signal: the global peak $n_4$ anchors the largest subtree. Secondary peaks that appeared before any larger node ($n_0$, which arrived before $n_2$) are absorbed when a larger node is inserted. The depth of any node encodes its relative amplitude significance: shallow nodes correspond to dominant features, deep nodes to fine-scale fluctuations.

\subsection{Path Decomposition}
\label{sec:decomposition}

Given a selected query node $s$, the decomposition algorithm enumerates all maximal monotone chains terminating at $s$ via backward traversal through the hierarchy. Two families of chains are recovered: \emph{decreasing chains}, along which amplitudes are strictly monotonically decreasing in forward time ($v_0 > v_1 > \cdots > v_k$), and \emph{increasing chains}, along which they are strictly increasing. These correspond respectively to descents from dominant peaks and ascents toward them.

\subsubsection{Density and Chronological Constraints}

Two admissibility conditions govern chain validity.

\begin{definition}[Chronologically Dense Path]
\label{def:dense-path}
A path $X = [n_0, n_1, \ldots, n_k]$ is \emph{chronologically dense} if for every consecutive pair $(n_i, n_{i+1})$, no intermediate node $m$ exists such that (i)~$\min(n_i, n_{i+1}) < m < \max(n_i, n_{i+1})$, (ii)~$m$ is visible from both $n_i$ and $n_{i+1}$, and (iii)~$m$ preserves the monotone trend of the chain.
\end{definition}

The density constraint prevents the omission of structurally relevant intermediate nodes. A second constraint enforces temporal causality: once the traversal moves backward in time, no subsequent forward jump is permitted.

\subsubsection{Chain Discovery}

Algorithm~\ref{alg:chain-discovery} recovers all maximal decreasing chains via recursive backward search. At each step, the frontier node is extended to all visible predecessors with strictly greater amplitude, subject to density and chronological admissibility. Recursion terminates when no further valid extension exists; chains of length $\geq 2$ are retained. Increasing chains are obtained identically with the magnitude inequality reversed.

\begin{algorithm}[H]
\caption{Find Maximal Decreasing Chains}
\label{alg:chain-discovery}
\begin{algorithmic}[1]
\Require MOVG structure, query node $s$
\Ensure Set of maximal decreasing chains ending at $s$
\Function{FindDecreasingChains}{MOVG, $s$}
    \State $\mathcal{C} \gets \emptyset$
    \Procedure{BackwardSearch}{path}
        \State $f \gets \text{path}[0]$ \Comment{Frontier node}
        \State $\text{extended} \gets \textbf{false}$
        \For{$p \in \text{predecessors}(f)$ \textbf{where} $Y[p] > Y[f]$}
            \If{\Call{IsDense}{$[p] \oplus \text{path}$} $\land$ \Call{IsChronological}{$[p] \oplus \text{path}$}}
                \State \Call{BackwardSearch}{$[p] \oplus \text{path}$}
                \State $\text{extended} \gets \textbf{true}$
            \EndIf
        \EndFor
        \If{$\neg\,\text{extended} \land |\text{path}| \geq 2$}
            \State $\mathcal{C} \gets \mathcal{C} \cup \{\text{path}\}$
        \EndIf
    \EndProcedure
    \State \Call{BackwardSearch}{$[s]$}
    \State \Return $\mathcal{C}$
\EndFunction
\end{algorithmic}
\end{algorithm}

From each maximal chain, all valid subpaths are generated by progressive truncation of the leading element, retaining only those containing $s$. This yields a comprehensive family of monotone subsequences at varying temporal scales, each anchored at the query node. Complexity is $O(k \cdot n)$ for chain discovery and $O(k \cdot L^2)$ for subpath generation, where $k$ denotes the number of maximal chains and $L$ the mean chain length.

\subsubsection{Worked Example (continued)}

Returning to $Y = [3, 1, 4, 2, 5, 1, 3, 2]$ with query node $s = 6$ ($y{=}3$), the decomposition recovers chains by traversing backward through the hierarchy. Longer chains encode coarser-scale trends; shorter subpaths capture finer local structure. Each chain is directly traceable to specific nodes and timestamps in the original signal.

\subsection{Path Signatures}
\label{sec:signatures}

Path signatures, derived from rough path theory [14], provide a method for reducing variable-length sequential data to fixed-dimensional numerical descriptors via iterated integrals [13]. Applied to the chains produced by MOVG decomposition, they yield compact geometric fingerprints that capture trend, curvature, and temporal asymmetry, properties no single summary statistic encodes simultaneously.

\subsubsection{The 1D Degeneracy}

For a univariate path $x = (x_1, \ldots, x_n) \in \mathbb{R}^1$, the depth-$N$ signature collapses to powers of the net increment:
\begin{equation}
S^{(k)}_{1,\ldots,1} = \frac{(\Delta x)^k}{k!}, \quad \Delta x = x_n - x_1
\label{eq:1d-collapse}
\end{equation}

All terms are deterministic functions of a single scalar $\Delta x$, rendering higher-order components informationally redundant. This degeneracy motivates embedding the path into a higher-dimensional space prior to signature computation.

\subsubsection{2D Embedding and Signature Definition}

Each chain $X = [n_0, n_1, \ldots, n_k]$ extracted from the MOVG is embedded into $\mathbb{R}^2$ via the time-value map:
\begin{equation}
\gamma : n_i \mapsto (t_i, y_i) = (n_i,\; Y[n_i])
\label{eq:2d-embedding}
\end{equation}

This lifts the path into the time-amplitude plane, where non-trivial signed areas exist and iterated integrals carry geometric meaning.

\begin{definition}[Depth-$N$ Signature]
\label{def:signature}
Let $\gamma : [t_1, t_n] \to \mathbb{R}^2$ be a piecewise-linear interpolation of the embedded chain. The depth-$N$ signature is the collection of iterated integrals
\begin{equation}
\mathrm{Sig}_N(\gamma) = \left\{ S^{(i_1, \ldots, i_k)} = \int_{t_1 \leq u_1 < \cdots < u_k \leq t_n} d\gamma^{i_1}_{u_1} \cdots\, d\gamma^{i_k}_{u_k} \;\middle|\; 1 \leq k \leq N,\; i_j \in \{1, 2\} \right\}
\label{eq:signature-def}
\end{equation}
For $d{=}2$ and $N{=}3$, this yields $(2^4 - 1)/(2-1) = 15$ components.
\end{definition}

\subsubsection{Extracted Scalar Projections}

Rather than utilising the full 15-term vector, three scalar projections are extracted per chain, each capturing a distinct geometric property of the path:

\begin{equation}
\begin{aligned}
\texttt{sig}[2] &= S^{(2)} = \int dy = y(t_n) - y(t_1) && \text{(net amplitude change)} \\[4pt]
\texttt{sig}[4] &= S^{(1,2)} = \int\!\!\int_{u_1 < u_2} dt\, dy && \text{(signed area / L\'{e}vy area analogue)} \\[4pt]
\texttt{sig}[8] &= S^{(1,1,2)} = \int\!\!\int\!\!\int_{u_1 < u_2 < u_3} dt\, dt\, dy && \text{(time-weighted acceleration)}
\end{aligned}
\label{eq:sig-projections}
\end{equation}

The first-order term $\texttt{sig}[2]$ quantifies overall displacement. The second-order term $\texttt{sig}[4]$ measures the signed area enclosed between the path and the chord connecting its endpoints, distinguishing concave from convex trajectories with identical net change. The third-order term $\texttt{sig}[8]$ captures temporal asymmetry: whether amplitude changes are concentrated early or late in the path. Together, these three projections provide a compact yet discriminative characterisation of each chain's geometry.

\subsubsection{Aggregate and Expanded Signatures}

Two modes of signature aggregation are employed across the chain families produced by decomposition:

\begin{definition}[Aggregate Signature]
\label{def:agg-sig}
For a set of $m$ chains $\{X_1, \ldots, X_m\}$ decomposed at query node $s$, the \emph{aggregate signature} computes the mean of each scalar projection across all chains:
\begin{equation}
\bar{\sigma}_k = \frac{1}{m} \sum_{j=1}^{m} \texttt{sig}[k]_j, \quad k \in \{2, 4, 8\}
\end{equation}
This yields a single 3-dimensional descriptor summarising the typical chain geometry at $s$.
\end{definition}

\begin{definition}[Expanded Signature]
\label{def:exp-sig}
The \emph{expanded signature} retains all 15 components of the depth-3 signature for each chain, concatenated with distributional statistics (variance, skewness, kurtosis) across chains. This provides a higher-dimensional but more expressive representation.
\end{definition}

The aggregate form is employed for computational efficiency and downstream interpretability; the expanded form is reserved for settings where richer characterisation is required.

\subsubsection{Worked Example (continued)}

Returning to the decreasing chain $[n_4, n_6]$ from $Y = [3, 1, 4, 2, 5, 1, 3, 2]$, the 2D embedding produces $\gamma = [(4, 5),\, (6, 3)]$. The signature projections are:
\begin{itemize}
    \item $\texttt{sig}[2] = 3 - 5 = -2$ \quad (net descent of 2 units)
    \item $\texttt{sig}[4] = \frac{1}{2}(t_1 - t_0)(y_1 - y_0) = \frac{1}{2}(2)(-2) = -2$ \quad (signed area below chord)
    \item $\texttt{sig}[8]$: for a two-point path, the third-order term is zero (no intermediate curvature to weight)
\end{itemize}

For the increasing chain $[n_5, n_6]$, the embedding produces $\gamma = [(5, 1),\, (6, 3)]$. The projections are:
\begin{itemize}
    \item $\texttt{sig}[2] = 3 - 1 = +2$ \quad (net ascent of 2 units)
    \item $\texttt{sig}[4] = \frac{1}{2}(1)(2) = +1$ \quad (signed area above chord)
    \item $\texttt{sig}[8] = 0$ \quad (two-point path)
\end{itemize}

These scalar values become features in the downstream machine learning pipeline. Crucially, each is traceable through the chain to specific nodes and timestamps in the original signal. This is the provenance that underpins the interpretability claim of the MOVG framework.

\subsection{Baseline Preprocessing Methods}
\label{sec:baselines}

Two established feature extraction methods are employed as comparative baselines. Each is summarised below with attention to its representational assumptions and interpretability properties.

\subsubsection{Fast Fourier Transform (FFT)}

The discrete Fourier transform decomposes a length-$N$ signal into $N$ complex-valued spectral coefficients:
\begin{equation}
X_k = \sum_{n=0}^{N-1} x_n \, e^{-2\pi i k n / N}, \quad k = 0, 1, \ldots, N-1
\label{eq:dft}
\end{equation}

Each coefficient $X_k$ encodes the amplitude $|X_k|$ and phase $\arg(X_k)$ of a sinusoidal component at frequency $k/N$. The fast Fourier transform computes Eq.~\ref{eq:dft} in $O(N \log N)$ time. As a feature extraction method, the amplitude spectrum is typically retained while phase information is discarded. This projection into the frequency domain identifies dominant periodicities but sacrifices temporal locality: the transform integrates over the entire window, providing no information about when a given frequency component is active. Individual spectral coefficients lack direct structural provenance in the time domain.

\subsubsection{Wavelet Decomposition}

The discrete wavelet transform addresses the temporal locality limitation of FFT by decomposing a signal into coefficients localised in both time and scale. A mother wavelet $\psi(t)$ is scaled and translated to produce a family of basis functions:
\begin{equation}
\psi_{a,b}(t) = \frac{1}{\sqrt{a}}\,\psi\!\left(\frac{t - b}{a}\right)
\label{eq:wavelet}
\end{equation}

where $a > 0$ controls scale (inversely related to frequency) and $b$ controls temporal position. Multiresolution analysis decomposes the signal into approximation and detail coefficients at successive dyadic scales, yielding a time-frequency representation. This provides finer temporal resolution at high frequencies and finer frequency resolution at low frequencies. However, the choice of mother wavelet and decomposition depth constitutes a basis commitment: the representation is optimal only for signals whose morphology matches the chosen wavelet family. The resulting coefficients are not directly traceable to named structural properties of the signal.

\section{Methodology}
\label{sec:methodology}

\subsection{Project Deliverables}
\label{sec:deliverables}

This project produced three deliverables:

\begin{enumerate}[leftmargin=2em, itemsep=0.4em]
    \item \textbf{Algorithmic specification and software package.} A formal specification of the MOVG framework comprising definitions, proofs of acyclicity, and pseudocode for all pipeline stages. This was accompanied by an installable Python package containing 13 modules with a \texttt{pyproject.toml} build configuration and a 45-unit test suite covering visibility checks, hierarchy construction, chain decomposition, and signature computation.

    \item \textbf{API documentation.} A reference manual documenting every public function and class in the MOVG package, following RESTful API conventions. This enables future researchers to reproduce the feature extraction pipeline and extend it to new datasets.

    \item \textbf{Empirical benchmark and backtracing tool.} A preprocessing benchmark evaluating MOVG features against FFT and wavelet baselines across seven datasets and six regression models, using walk-forward cross-validation. This was accompanied by a post-inference backtracing tool that maps any model prediction to specific timestamps in the raw signal via the SHAP-to-chain-to-node provenance chain.
\end{enumerate}

\subsection{Feature Extraction Pipeline}
\label{sec:feature-pipeline}

The MOVG package provides a single \texttt{extract\_features()} method that produces a fixed-length vector of 32 scalar features per window, organised across eight categories: core graph and chain statistics (12), tree structure (3), amplitude on tree (3), degree distribution (3), spectral properties (3), centrality measures (3), graph-theoretic coefficients (3), and visibility-time statistics (2). The full list is given in Appendix~\ref{app:feature_list}.

\subsubsection{Feature Reduction Pipeline}

The final 32-feature representation was obtained through a three-stage reduction pipeline applied to the initial extraction output.

\textbf{Stage 1: Removal of non-MOVG features (167 $\to$ 155).} An earlier version of the extraction pipeline produced 167 features, of which 12 belonged to a raw window statistics category (\texttt{win\_mean}, \texttt{win\_std}, \texttt{win\_rms}, and nine others). These statistics are computed directly from the signal window and are not derived from the MOVG graph structure. During preliminary experiments, these features were found to inflate the apparent performance of certain models, particularly during flat (healthy-phase) signal segments where the raw statistics created a near-trivial mapping to the target. Removing them ensured that all subsequent evaluation measured the contribution of MOVG-derived structural features only. This left 155 genuine structural features across 14 categories.

\textbf{Stage 2: Correlation and collinearity filtering (155 $\to$ $\sim$48).} Pairwise Pearson correlation was computed between all 155 features. Where two features exhibited $|r| > 0.95$, the feature with the lower absolute correlation to the target was dropped. The surviving features were then screened with variance inflation factors (VIF): any feature with VIF $> 5$ was removed iteratively until all remaining features had VIF $\leq 5$. This stage eliminated redundant features that would contribute multicollinearity without adding predictive information.

\textbf{Stage 3: Domain-driven curation (48 $\to$ 32).} The remaining features were grouped by their 14 structural categories (core graph statistics, tree structure, amplitude, degree distribution, spectral, centrality, graph-theoretic, visibility-time, and six signature sub-categories). Within each category, the top one to three features by target correlation and interpretability were retained. The guiding principle was to preserve at least one representative descriptor per structural category while avoiding redundancy within categories. The result is a compact 32-feature vector in which every feature is both MOVG-derived and structurally distinct.

All results in this report use the 32-feature representation produced by this pipeline. No further dimensionality reduction was applied: the feature set was designed to be compact by construction, retaining one to three descriptors per structural category rather than exhaustively enumerating all possible statistics.

\subsubsection{Baseline Feature Sets}

Two baseline feature sets were computed on identical windows for fair comparison: FFT (amplitude spectrum coefficients) and discrete wavelet transform (detail and approximation coefficients at dyadic scales). All feature sets share the same train/test splits and evaluation protocol.

\subsubsection{Windowed Construction and Multi-Scale Capture}

The MOVG construction has $\mathcal{O}(n^2)$ worst-case complexity in the number of samples. For the dataset lengths considered here (up to several thousand observations), constructing a single MOVG from the full series would be computationally prohibitive and would produce a tree so large that the resulting feature vector would conflate local and global structure indiscriminately. Windowed construction addresses both concerns: each window is short enough for the $\mathcal{O}(n^2)$ visibility-check stage to complete in tractable time, and the resulting tree is localised enough for its structural features to reflect the signal morphology within that window specifically.

Despite this localisation, the hierarchy within each window naturally encodes structure at multiple temporal scales. Long chains through the tree capture coarse trends spanning the full window length: the descent from a dominant peak through several intermediate nodes reflects a broad downward trajectory covering many time steps. Short chains and shallow subpaths capture fine-grained, local fluctuations between adjacent or near-adjacent points. The depth dimension of the tree separates these scales: root-level nodes correspond to the window's dominant features, while deep leaf nodes represent minor oscillations.

The model learns long-term trends through the evolution of structural features across successive windows, not from any single window in isolation. Because the walk-forward evaluation protocol uses an expanding training window, the model observes MOVG trees from progressively more data over time. As the signal evolves, so does the tree structure: a healthy-phase window may produce a shallow, sparsely branched tree, while a degradation-phase window produces a deeper, more complex tree with higher branching factors. The structural features therefore track temporal evolution across windows. The downstream regression model receives a sequence of feature vectors, each summarising one window, and learns to associate changes in tree structure (increasing depth, rising branching factor, shifting signature statistics) with the target variable. This is the mechanism by which the windowed approach captures both short-term (within-window) and long-term (across-window) dynamics without requiring a single monolithic graph.

\subsection{Models and Evaluation}
\label{sec:models-evaluation}

Six regression models were employed, spanning four learning paradigms: tree-based (XGBoost [20], LightGBM, Random Forest), kernel-based (SVR), linear (Ridge Regression), and instance-based (K-Nearest Neighbours). This diversity tests whether MOVG features benefit models uniformly or proportionally to their inability to discover structure independently from raw inputs.

SVR was initially tuned with $C{=}0.1$, which produced near-constant predictions across all feature sets. The regularisation penalty dominated the loss, causing the model to ignore input features entirely. Re-tuning with higher $C$ values recovered meaningful predictions. Both configurations are reported to demonstrate the sensitivity of kernel methods to hyperparameter selection when operating on structural features.

\subsubsection{One-Step-Ahead Prediction}

All models predict one step ahead: given the feature vector extracted from window $t$, the model outputs the target value at time $t{+}1$. This choice is deliberate. Multi-step forecasting introduces compounding error and conflates two distinct questions: whether the features are informative (a representation question) and whether the model can propagate predictions accurately over multiple horizons (a model-architecture question). By restricting to a single-step horizon, the evaluation isolates the quality of the feature representation from the forecasting strategy. The one-step setting also maximises the utility of the backtracing tool, since each prediction maps to a single input window and therefore to a single, unambiguous set of MOVG chains and graph nodes.

\subsubsection{Walk-Forward Cross-Validation}

Evaluation followed an expanding-window walk-forward cross-validation protocol [16, 21]. The training set grows with each split while the test set advances forward in time, preventing data leakage. This design preserves temporal ordering and reflects realistic deployment conditions in which a model is periodically retrained as new data arrives.

The expanding (rather than sliding) window was chosen because historical observations remain informative: discarding early data would sacrifice context that may improve generalisation. In time series with evolving dynamics, earlier observations establish the baseline regime against which later changes become detectable. An expanding window allows the model to retain this baseline context while incorporating new data, which is particularly important for datasets that transition between distinct operating regimes over time.

Standard $k$-fold cross-validation is inappropriate for time series because it breaks temporal ordering, allowing future observations to leak into the training set and producing optimistically biased error estimates. Walk-forward validation avoids this by ensuring that the model is always trained on past data and evaluated on unseen future data, matching the conditions under which a deployed model would operate.

All three feature sets (MOVG-32, FFT, wavelet) share identical splits, targets, and evaluation metrics (RMSE, MAE) to ensure fair comparison.

\subsection{Post-Inference Backtrace}
\label{sec:backtrace}

The central contribution of this work is not predictive performance but the ability to explain why a model produced a given output. The backtrace procedure establishes a three-layer chain of provenance from a model prediction to identifiable events in the raw signal. The procedure operates as follows:

\textbf{Layer 1: Feature attribution.} Given a trained model and a test input, SHAP (SHapley Additive exPlanations) [19] computes a per-feature attribution score $\phi_f$ for every feature $f$ in the input vector. The features are ranked by $|\phi_f|$, and the top-$k$ contributors are selected for inspection.

\textbf{Layer 2: Feature-to-graph mapping.} Each high-attribution feature is mapped to the MOVG graph structure that produced it. The mapping depends on the feature category. A signature-derived feature such as \texttt{subtree\_sig8\_std} maps to a specific set of root-to-leaf paths in the hierarchy; an amplitude feature such as \texttt{root\_amp\_cv} maps to the set of root nodes and their amplitudes; an edge geometry feature maps to specific parent-child edges and their spatial properties.

\textbf{Layer 3: Graph-to-signal projection.} The graph elements identified in Layer~2 are projected back onto the original time series via their stored time indices and amplitude values. Each node in the MOVG retains its original timestamp $t_i$ and amplitude $y_i$, so the projection is a direct lookup. The output is a finite set of $(t, y)$ pairs identifying the precise temporal events that drove the prediction.

\begin{algorithm}[H]
\caption{Post-Inference Backtrace}
\label{alg:backtrace}
\begin{algorithmic}[1]
\Require Trained model $\mathcal{M}$, input feature vector $\mathbf{x}$, MOVG structure $\mathcal{G}$, raw signal $Y$
\Ensure Highlighted timestamps and amplitudes in $Y$
\Function{Backtrace}{$\mathcal{M}, \mathbf{x}, \mathcal{G}, Y$}
    \State $\hat{y} \gets \mathcal{M}.\text{predict}(\mathbf{x})$
    \State $\boldsymbol{\phi} \gets \text{SHAP}(\mathcal{M}, \mathbf{x})$ \Comment{Per-feature attributions}
    \State $F_k \gets \text{top-}k\text{ features by } |\phi_i|$
    \For{$f \in F_k$}
        \State $\mathcal{N}_f \gets \text{MapToNodes}(\mathcal{G}, f)$ \Comment{Graph nodes producing $f$}
        \State $\mathcal{T}_f \gets \{(t_n,\, Y[t_n]) : n \in \mathcal{N}_f\}$ \Comment{Timestamps + amplitudes}
    \EndFor
    \State \Return $\{(f,\, \phi_f,\, \mathcal{T}_f) : f \in F_k\}$
\EndFunction
\end{algorithmic}
\end{algorithm}

To illustrate with the toy example: suppose a model trained on the 32 MOVG features predicts a value for the window $Y = [3, 1, 4, 2, 5, 1, 3, 2]$, and SHAP identifies \texttt{subtree\_sig8\_std} as the top contributor. The backtrace maps this feature to the root-to-leaf paths in the MOVG forest (for example, $n_4 \to n_6 \to n_7$), extracts the time indices $\{4, 6, 7\}$ and their amplitudes $\{5, 3, 2\}$, and highlights these in the raw signal. The practitioner can now see that the model's prediction was driven by the descent pattern from the global peak through two subsequent values, rather than by an opaque statistical summary.

This contrasts with SHAP applied to spectral or statistical features, where an attribution to a Fourier coefficient or an autocorrelation statistic identifies what type of property mattered but not which specific temporal events produced it.

\subsubsection{Limitations of SHAP for Structural Features}

SHAP assumes feature independence when computing Shapley values via the kernel or tree explainer [15, 19]. Several MOVG features are structurally correlated: for instance, \texttt{tree\_depth} and \texttt{n\_leaves} both depend on the branching structure of the hierarchy, and the three signature statistics share a common decomposition stage. When features are correlated, SHAP attributions can be unstable, redistributing credit between correlated features across similar inputs. The backtrace remains valid (each feature still maps to identifiable graph elements), but the \emph{ranking} of feature contributions should be interpreted with caution.

Alternative attribution methods that handle correlated features more robustly include permutation importance (which measures performance degradation when a feature is shuffled), ablation-based attribution (which removes features and observes the effect on output), and Integrated Gradients for differentiable models. For the tree-based models used in this evaluation, SHAP's TreeExplainer computes exact Shapley values conditional on the tree structure [15], which partially mitigates the correlation issue.

The full RMSE table for each dataset is reported in the Appendix. Across the seven per-dataset tables, MOVG records the row-best (best preprocessing for a given model) on 39 of the 41 populated rows. To summarise the joint effect of preprocessing and model selection, the five lowest-ranked (preprocessing, model) combinations across all seven datasets are all MOVG variants: LGBM (mean rank 2.00), XGB (2.67), Ridge (2.71), RF (3.57), and SVR (4.14). MOVG with KNN is the only MOVG combination outside the top five (mean rank 11.83). All six wavelet combinations occupy ranks 6 to 12 inclusive, and all six FFT combinations occupy ranks 13 to 18 inclusive.

\subsection{Feature reduction}
\label{sec:res_features}

The three-stage reduction pipeline described in Section~\ref{sec:feature-pipeline} reduced the initial 167-feature extraction to 32 MOVG-derived structural features. In the first stage, 12 raw window statistics (\texttt{win\_*}) were removed because they are not MOVG-derived, leaving 155 genuine structural features. In the second stage, pairwise correlation filtering ($|r| > 0.95$) and variance inflation factor screening (VIF $> 5$) removed redundant and collinear features, reducing the set to approximately 48. In the third stage, domain-driven curation selected the top one to three features per structural category, yielding the final 32-feature vector across eight categories (Appendix~\ref{app:feature_list}). No post-hoc dimensionality reduction was applied beyond this pipeline: the feature set was designed to be compact by construction, with each category contributing descriptors that are both informative and structurally distinct. All RMSE figures reported in Sections~\ref{sec:res_cross} and~\ref{sec:res_per_ds} are computed on this 32-feature representation.

\subsection{Feature importance}
\label{sec:res_shap}

SHAP values are computed on the best-ranked model (MOVG with LGBM, mean rank 2.00) using the held-out test partition of each dataset. In the appendix, the SHAP summary for a representative dataset is reported, ranking the 32 reduced features by mean absolute contribution. Structural features, particularly root amplitude statistics, subtree signature statistics, and leaf amplitude range, occupy the upper portion of the ranking, ahead of aggregate graph descriptors.

SHAP plots can be seen in the appendix as well, with a beeswarm, heatmap and waterfall plots for the top-ranked features. The plots show that the most important features are not only structurally interpretable but also exhibit meaningful relationships with the target variable: for instance, higher root amplitude coefficient of variation (\texttt{root\_amp\_cv}) is associated with higher predicted values, while higher subtree signature standard deviation (\texttt{subtree\_sig8\_std}) is associated with lower predicted values. These relationships are consistent across datasets, suggesting that the MOVG features capture generalisable structural properties of the signal that are relevant for forecasting.

\section{Discussion}
\label{sec:discussion}

The empirical findings reported in Section~\ref{sec:results} support three claims about the MOVG framework: that it produces predictions which are mechanically traceable to identifiable structures in the input signal, that it generalises across signal domains without per-domain tuning, and that it interacts with downstream regression models in a manner consistent with its underlying representational properties. This section develops each claim in turn, then examines the limitations of the present evaluation.

\subsection{Interpretability: from prediction to chain to time index}
\label{sec:disc_interp}

The defining design objective of the MOVG framework is the existence of an end-to-end interpretability chain that links a model's prediction to a finite, identifiable subset of the raw signal. This chain is now visible in the experimental results.

A SHAP analysis (Figure~\ref{fig:shap_summary}) attributes a model prediction to a small set of features, each of which corresponds to a structural property of a specific chain in the magnitude hierarchy. The backtracing tool (Figures~\ref{fig:backtrace_a} and~\ref{fig:backtrace_b}) then maps each contributing chain to its constituent node indices in the time domain. Every step in this chain is deterministic given a fixed feature-extraction pipeline.

This property distinguishes the MOVG approach from both baselines. FFT preprocessing produces frequency-band magnitudes that are global aggregates over the input window, with no preserved correspondence between an active feature and a localised event in time. Wavelet decomposition retains time-frequency localisation, but its features describe the energy in a band at a scale, rather than the geometric structure of any individual event. The MOVG chain-to-prediction mapping is therefore a property unique to the graph-based representation and is the central methodological contribution of the project.

The practical consequence is that a model trained on MOVG features can be inspected at the level of a single test prediction. Given a test index, the user can recover the chains that drove the prediction, the magnitude ranks of the nodes in those chains, and the signature projection values associated with them. This is the operational sense in which a downstream user can answer the question ``the model predicted this because of which part of the signal.''

\subsection{Cross-domain generalisation}
\label{sec:disc_generalise}

A second observation from Section~\ref{sec:res_cross} is that MOVG records the lowest mean RMSE on every one of the seven datasets evaluated. The datasets span four distinct signal regimes: industrial sensor data with seasonal and trending components (ETTh1, ETTh2, weather), foreign-exchange close prices with non-stationary drift (EUR/USD, SGD/USD), commodity prices with extended trending phases (Gold), and a volatility index with heavy-tailed innovations (VIX). The same 32-feature MOVG representation, with no per-domain feature engineering or tuning, produces the lowest RMSE on each.

The relative gain varies between 5.3\% (VIX) and 29.5\% (EUR/USD). The lower end corresponds to series with high innovation variance and short autocorrelation, where the marginal value of any structural representation is constrained by irreducible noise. The upper end corresponds to series dominated by smooth, multi-scale trend structure, precisely the regime in which a hierarchical magnitude-ordered representation is well matched to the data.

\subsection{Model-by-model behaviour}
\label{sec:disc_models}

The per-dataset results report a clear ordering: the five lowest-ranked combinations are all MOVG-based, with LGBM, XGB, Ridge, RF, and SVR occupying the top five positions. The single MOVG combination outside this group is MOVG with KNN, which ranks 12th of 18.

This split is informative about the geometry of the MOVG feature space. Tree-based models are insensitive to feature scale and capable of learning thresholded interactions; their gain reflects the additional information contained in the structural features. Ridge and SVR depend on linear or kernelised distance computations and perform consistently with MOVG, indicating that the 32-feature representation is approximately well-conditioned.

KNN under-performs because its Euclidean distance metric assumes all features contribute equally to similarity and cannot down-weight uninformative features. The MOVG feature set retains features of heterogeneous semantic type (amplitude statistics, depth distributions, signature projections, graph descriptors) and is therefore unlikely to be isotropic in the unweighted Euclidean sense. The under-performance of MOVG with KNN is consistent with this property rather than with any deficiency of the MOVG representation itself.

\subsection{Comparison to baseline preprocessing}
\label{sec:disc_baselines}

Wavelet preprocessing places second across all seven datasets and FFT places uniformly last. This ordering is consistent with what each method retains from the input signal. FFT discards phase information and replaces the window with band magnitudes; the resulting representation is approximately stationary and poorly matched to non-stationary series. Wavelet decomposition preserves time-localisation at multiple scales. MOVG retains both magnitude ordering and chronological ordering in a single representation, the structural property the other two methods discard. The ranking can therefore be read as an ordering by representational completeness rather than by model capacity.

\subsection{Honest caveats}
\label{sec:disc_caveats}

Two caveats apply to the empirical results. First, the raw window statistics (\texttt{win\_*} features) that were present in the initial 167-feature extraction were identified as non-MOVG-derived and removed in the first stage of the reduction pipeline. All RMSE figures in this report use the final 32-feature MOVG-only representation.

Second, the SVR hyperparameters used in the cross-dataset evaluation were tuned conservatively at the start of the experimental campaign. A more thorough hyperparameter search may further improve the SVR results. The relative ordering of the preprocessing methods is robust to this consideration, since the same SVR configuration is applied across all three preprocessing inputs.

\subsection{Synthesis}
\label{sec:disc_synthesis}

Taken together, the results establish that MOVG produces a feature representation that (i) is competitive or superior to standard preprocessing methods across a diverse set of regression tasks, (ii) admits direct backtracing from prediction to source signal, and (iii) interacts with downstream models in a manner consistent with the geometric properties of its reduced feature set. The interpretability property is what motivates the framework, and the empirical results show that this property is not obtained at a cost in predictive accuracy.

\section{Conclusion}
\label{sec:conclusion}

This project set out to develop a time series preprocessing framework that produces an interpretable feature representation without sacrificing downstream predictive accuracy. The framework, the Magnitude-Ordered Visibility Graph (MOVG), constructs a directed acyclic forest from a time series by combining visibility checks with a magnitude-based hierarchical ordering, decomposes the resulting structure into chains, and extracts a fixed-length feature vector via path-signature projections and structural descriptors. The framework was formally specified, implemented as a Python package with a documented API, and evaluated against established preprocessing methods on a diverse set of regression tasks.

Three contributions follow from the work. First, the MOVG construction admits a deterministic backtracing operation that maps a downstream model prediction to a finite, identifiable set of indices in the raw input signal, via the chains that produced its dominant feature contributions. This property is the central methodological contribution of the project and is not present in the baseline preprocessing methods evaluated.

Second, a 32-feature MOVG representation, obtained through a three-stage pipeline of non-MOVG feature removal, correlation and VIF filtering, and domain-driven curation across 14 feature categories, retains the predictive content of the full feature set and remains effective across all evaluation regimes considered.

Third, the empirical evaluation across seven datasets and six regression models, summarised in Table~\ref{tab:master_summary}, establishes that MOVG records the lowest mean RMSE on every dataset, with a mean improvement of 15.1\% over the best non-MOVG baseline.

The project's stated aims have been met. The framework is formally specified, the package is operational, and the empirical comparison is complete and consistent with the interpretability hypothesis.

\section{Constraints and Future Work}
\label{sec:constraints}

\subsection{Implementation constraints}
\label{sec:constr_impl}

The reference implementation is built on top of \texttt{NetworkX} [22] and uses Numba just-in-time compilation to accelerate the visibility-check kernel. The visibility-check stage is $\mathcal{O}(n^{2})$ in the worst case for a series of length $n$. The horizontal-visibility variant admits an $\mathcal{O}(n \log n)$ construction [6], but this variant discards the slope-based ordering that the magnitude hierarchy depends on, and is therefore not interchangeable with the MOVG used in this work.

The current implementation is single-threaded outside the JIT-compiled kernel and runs on CPU. For the dataset sizes considered here, runtimes are tractable but increase super-linearly with series length. A GPU-resident reimplementation of the visibility-check stage is a natural target for future work. The dependency on \texttt{NetworkX}, which stores graphs as Python dictionaries, further constrains memory efficiency and parallelisation. Migrating the graph backend to an array-based representation would reduce overhead and enable batch processing of multiple windows in parallel.

\subsection{Methodological constraints}
\label{sec:constr_method}

The evaluation is restricted to univariate time series. The MOVG construction relies on a single magnitude ordering, which is well-defined only on a scalar series. The literature on multiplex visibility graphs provides a starting point for multivariate extension: each channel could form its own layer, and inter-layer edges would capture cross-channel structure [3, 4].

The evaluation is also restricted to regression tasks with a single horizon. Classification, multi-step forecasting, and anomaly detection were not evaluated. The interpretability properties are expected to transfer, since they are properties of the feature representation rather than of the prediction target, but this expectation is not empirically verified here.

The seven datasets evaluated span four signal regimes, but all are univariate and relatively short compared to industrial-scale deployments. The cross-domain generalisation claim, while supported by the data, would be strengthened by evaluation on longer series and on domains with fundamentally different temporal structure, such as audio or biomedical signals.

\subsection{Risk management and mitigation}
\label{sec:constr_risk}

Several risks were identified during the project and managed through design choices. The primary technical risk was that the $\mathcal{O}(n^2)$ construction cost would render the framework impractical for the target dataset sizes. This was mitigated by windowed processing, which bounds the input length to each MOVG construction, and by Numba JIT compilation of the inner visibility loop. A second risk was feature leakage: the initial 167-feature set contained 12 raw window statistics (\texttt{win\_*}) that were not MOVG-derived. These were identified through inspection and removed in the first stage of the reduction pipeline, bringing the feature count to 155. The subsequent correlation, VIF, and domain-curation stages reduced the set further to 32, and all experiments were re-run on this final representation.

Schedule risk was managed through a day-by-day plan with hard-gate checklists. The plan was revised twice during the project when intermediate results required additional experiments (SVR re-tuning, win\_* feature removal).

\subsection{Intellectual property and data management}
\label{sec:constr_ip}

The MOVG package was developed as original work and is distributed as an installable Python package with a \texttt{pyproject.toml} build configuration. All code was version-controlled in a private Git repository throughout development. The seven evaluation datasets are publicly available: the ETTh1/ETTh2 and weather datasets are from established benchmarks, the financial datasets are sourced from public market data, and no personally identifiable information is present in any dataset.

\subsection{Ethical considerations and EDI}
\label{sec:constr_ethics}

The MOVG framework is a general-purpose preprocessing tool and does not process personal, demographic, or protected-characteristic data. The datasets used for evaluation contain no individual-level data. The interpretability contribution of the framework is itself an ethical consideration: by enabling practitioners to trace model predictions to specific signal events, MOVG reduces the opacity that can lead to unjustified trust in or rejection of model outputs. This is particularly relevant in safety-critical domains such as predictive maintenance, where opaque predictions may lead to premature or delayed intervention.

The framework and its documentation are designed to be accessible to researchers regardless of background. The package includes a 45-unit test suite, RESTful-style API documentation, and a worked example that does not assume domain-specific knowledge. The evaluation uses publicly available datasets to ensure reproducibility.

\subsection{Future work}
\label{sec:constr_future}

Three directions follow from these constraints. First, extension of MOVG to the multivariate case via multiplex visibility graph layers, which would enable application to multi-sensor systems. Second, GPU-resident reimplementation of the visibility-check stage to support longer input series. Third, application of the backtracing tool to a fault-detection or fault-diagnosis task, where the value of mapping a model prediction to localised signal indices is most immediate.
